# conscience-audit-committee (양심감사위원회)

현재 버전: **v2.0.1**

> **"국민의 양심을 투명하게, 공정하게 감사합니다."**  
> 이음중앙관리국 산하 가상행정기관 양심감사위원회 공식 웹 포털  
> 🔗 **서비스 바로가기**: [https://12cchris.github.io/conscience-audit-committee/](https://12cchris.github.io/conscience-audit-committee/)

본 사이트는 실제 기관과 무관한 패러디 웹 애플리케이션으로, 사용자가 본인 또는 타인의 양심 상태를 접수하고 심의를 거쳐 공식 감사 결과 통지서를 발급받는 서비스입니다.

---

## 🏛️ 주요 기능

- **고시·공고**: 위원회의 공식 공고 안내 및 관리자 모드
- **감사 신청**: 자기 양심 / 타인 양심 / 기관·단체 양심 감사 신청 및 자가진단 (신청 직후 상태: **검토중**)
- **관리자 허가**: 관리자가 신청을 **허가**해야 '심의 개시'가 가능하며, **반려**할 수도 있음 (허가 → 반려 변경 가능)
- **접수 내역 & 심의 개시**: 접수 번호 부여, 허가된 신청만 심의를 거쳐 공식 '감사 결과 통지서' 발급
- **통지서 인쇄**: 실제 공문서 양식(위원장 직인 포함) 기반 인쇄 최적화
- **양심 불량 신고**: 비양심 행위 익명 신고 (**검토중** → 관리자 허가 시 게시, 게시된 신고만 공감 투표 가능)
- **감사 보고서**: 적합/보완/부적합 통계 및 신고 현황 그래프, 로컬 데이터 백업·복원(JSON) 기능

## ☁️ Firebase 연결 (모든 방문자의 신고·신청을 관리자가 한곳에서 허가)

`firebase-config.js` 가 비어 있으면(기본값) 서버 없이 **각자 브라우저에만 저장**됩니다. 아래 순서로 설정하면 서버(Firestore)에 저장되어, 방문자가 낸 신청·신고가 관리자 화면에 모이고 허가된 건만 모두에게 보입니다. (무료 Spark 요금제로 충분합니다.)

1. [Firebase 콘솔](https://console.firebase.google.com) → **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다)
2. 프로젝트 개요 → **웹 앱(`</>`) 추가** → 나오는 `firebaseConfig` 값을 `firebase-config.js` 의 `config` 에 붙여넣기
3. **Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호 사용 설정**
4. Authentication → **사용자 → 사용자 추가** 로 관리자 계정(이메일·비밀번호) 만들기 → 만들어진 계정의 **사용자 UID** 복사
5. **Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3` 서울, **프로덕션 모드**)
6. Firestore → **규칙** 탭에 `firestore.rules` 전체를 붙여넣고, `PASTE_ADMIN_UID_HERE` 를 4번의 UID 로 바꾼 뒤 **게시**
7. `firebase-config.js` 의 `adminUid` 에도 같은 UID 를 입력
8. Authentication → **설정 → 승인된 도메인** 에 `12cchris.github.io` 추가
9. (선택) Authentication → 설정 → 사용자 작업에서 **가입 허용 해제** — 관리자 외 계정이 만들어지는 것을 막습니다
10. 커밋·푸시 후 사이트에서 **관리자 모드 → 이메일/비밀번호 로그인**

### 서버 모드에서의 동작
- 신청·신고는 **검토중** 으로 서버에 저장되고, 신청한 본인(같은 브라우저)과 관리자만 볼 수 있습니다.
- 관리자가 **허가** 하면 모든 방문자의 목록에 나타납니다. (신청은 본인이 `심의 개시`, 신고는 누구나 공감 가능)
- 공고는 관리자만 등록·삭제하며 모든 방문자에게 보입니다.
- 삭제는 관리자만 할 수 있습니다. 접수번호는 연도별로 서버에서 순서대로 발급됩니다.
- 관리자 화면의 백업(JSON)은 서버 데이터를 내려받는 용도이며, 복원·초기화는 로컬 모드에서만 지원합니다.
- 기존에 브라우저에만 쌓아 둔 로컬 데이터는 서버로 옮겨지지 않습니다.

### 알아 둘 점
- `심의 개시` 의 판정(무작위)은 방문자의 브라우저에서 계산됩니다. 개발자도구를 쓰면 결과를 고를 수 있는 재미용 판정입니다.
- 누구나 신청·신고를 보낼 수 있으므로(길이 제한은 규칙으로 적용) 스팸이 걱정되면 Firebase **App Check** 를 추가로 켜는 것을 권합니다.

## ℹ️ 참고

- 서버 미연결(로컬) 모드에서는 모든 데이터가 **각자의 브라우저(localStorage)** 에만 저장되어, '관리자 허가'도 그 브라우저 안에서만 의미가 있습니다.
- 데이터는 [감사 보고서]의 **백업(JSON)** 으로 내려받고 로컬 모드에서는 **백업 복원** 으로 되돌릴 수 있습니다.
- `commit.bat`: 더블클릭하면 메시지를 입력받아 커밋·푸시하고, `commit.bat "메시지"`처럼 인자로 줄 수도 있습니다.
